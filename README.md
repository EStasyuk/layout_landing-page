# Landing Page

A simple responsive landing page built from a Figma design.  
The goal of the project is to practice layout building, styling with Sass, and deploying a static website.

## Live Preview
[Demo Link](https://github.com/EStasyuk/layout_landing-page/)  

## Design Reference

## Technologies Used
- HTML5
- CSS3 / Sass (SCSS)
- GitHub Pages

## Getting Started

### Clone the repository
```bash
git clone https://github.com/your-username/layout_landing-page.git
cd layout_landing-page


Install dependencies:
npm install
# or
yarn install

Run the project locally:
npm start
